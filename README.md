# MomOS

An all-in-one daily companion for mum: trackers, memory assistant, wellness, family sync, learning and gamification.

- **App:** Flutter web (installable PWA)
- **Backend:** Supabase (auth, Postgres with RLS)
- **Hosting:** GitHub Pages, deployed on every push to `main`
- **Live:** https://thetechguydev.github.io/MomOS/

Database migrations live in `supabase/migrations/`.
